This live demonstration follows the Parkinson’s digital-voice pathway end to end: 22 acoustic biomarkers, classical preprocessing, quantum learning, model consensus and an explainable assessment report.

SYSTEM AT A GLANCE

One clear path from digital biomarker to decision support

The current SIH module begins with an extracted acoustic feature vector so every inference can be reproduced and audited.

01

Input

22 pre-extracted voice biomarkers from sustained phonation: pitch, jitter, shimmer, noise and nonlinear dynamics.

The user never enters the diagnosis/status label.
02

Hybrid engine

Training-only imputation and scaling, Random Forest baseline, 4-feature quantum encoding, VQC and fidelity-kernel QSVM.

Four selected dimensions map to four qubits.
03

Output

Hybrid pattern index, model agreement, model-by-model scores, cohort comparison, feature drivers and a printable assessment report.

The index is not a calibrated disease probability.
04

Next action

Use the result for research screening or triage support, then escalate concerning patterns for qualified neurological evaluation.

Never used as a standalone diagnosis.

WORKING MULTIMODAL PROTOTYPE

Three independently trained signal branches, one fusion layer

Voice, gait and handwriting are evaluated by their own validated models and combined only at decision level. This avoids training a false joint model across unrelated research participants.

Fusion method: validation-weighted late fusion. Branch weights are based on research ROC-AUC above chance and renormalized across available modalities.

HOW IT WOULD BE USED

From voice capture to clinical review

A supervised workflow connects signal capture, feature extraction, hybrid QML assessment and qualified review.

1Capture

Sustained vowel / standardized voice recording collected in a supervised screening workflow.

2Extract

Acoustic engine derives pitch, jitter, shimmer, HNR/NHR and nonlinear voice features.

3Assess

QuantumMed preprocesses the feature vector and runs RF + VQC + fidelity-kernel QSVM.

4Review

Report is reviewed as decision support; concerning or indeterminate patterns are escalated appropriately.
